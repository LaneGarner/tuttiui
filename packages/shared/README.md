# @tutti-ui/shared

Shared utilities for the tutti-ui design system. Includes `cn()` (clsx + tailwind-merge), `ThemeProvider`, and `useTheme`.

## Install

```bash
npm install @tutti-ui/shared
```

## Usage

```tsx
import { cn, ThemeProvider, useTheme } from '@tutti-ui/shared';
```

# @tuttiui/shared

Shared utilities for the tuttiui design system. Includes `cn()` (clsx + tailwind-merge), `ThemeProvider`, and `useTheme`.

## Install

```bash
npm install @tuttiui/shared
```

## Usage

```tsx
import { cn, ThemeProvider, useTheme } from '@tuttiui/shared';
```
